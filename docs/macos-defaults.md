# macOS defaults (`.osx`)

Este repo incluye un script completo **`.osx`** (no es un stub vacío).

- **Origen en la Mac:** `~/.osx` → symlink a `~/Development/GitHub/dotfiles/.osx`
- **Autor / estilo:** script tipo Jeff Geerling (cabecera `@author Jeff Geerling`), ~274 líneas / ~12.7 KB
- **Uso típico:** revisar y ejecutar con cuidado; algunas secciones requieren root/`sudo`. Opción `--no-restart`.

```bash
# Revisar primero
less .osx
# Ejecutar (opcional)
./.osx --no-restart
```

El archivo completo vive en la raíz del repo: [`.osx`](../.osx).

Temas que cubre (resumen): UI/UX, trackpad/teclado, pantallas/screenshots, Finder, Dock, Safari, Mail, Terminal, Activity Monitor, App Store, etc.
